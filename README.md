🌐 Technical Architecture & File Structure

This module uses a modular three-file architecture designed for effortless deployment and maintenance:

huokaingthara_football_club_home_announcement/
├── index.html     # Main Home & Announcement page markup with bilingual elements
├── style.css      # Modern dark cyberpunk/athletic theme (#0f172a slate, #00f2fe cyan)
├── script.js      # Dynamic language switcher toggling between English (EN) and Khmer (KH)
└── README.md      # Comprehensive repository documentation


Key Features:

Instant Bilingual Toggle: Seamless switching between English (.en-text) and Khmer (.kh-text) via the navigation switch.

Modern Cyberpunk Theme: Designed with a dark athletic aesthetic optimized for desktop and mobile displays.
